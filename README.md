# Sixty-Programs-for-the-Sinclair-ZX-Spectrum
60 exhaustively tested ZX Spectrum type-in listings! Retro 8-bit Sinclair BASIC programs, arcade games, brain-teasers &amp; utilities from the 1980s classic listing book by Erskine, Walwyn, Stanley &amp; Bews. Includes fully verified code listings with user-defined graphics support. Get your fingers on the keyboard and defend Earth from vampire cats!
